# Victor de Sviatkliff

Portfolio pessoal de **Victor de Sviatkliff**, nome artístico de **Victor Lucas da Conceição Rodrigues**. Também conhecido online como **xiaop** e **dorayakito**.

O site apresenta projetos de síntese vocal, software livre e criação digital, incluindo Kamafeu Studio, Copaiba NEO e VIVA Open Synth Brasil.

## Site

Este é um site estático, feito com HTML e CSS. Não precisa instalar dependências nem executar um processo de build.

Para visualizar localmente, abra `index.html` no navegador. Para publicar no GitHub Pages, use o repositório de perfil:

```text
victorsviartkliff/victorsviartkliff.github.io
```

Depois de enviar os arquivos para a branch `main`, ative o GitHub Pages nas configurações do repositório, selecionando `Deploy from a branch`, branch `main` e pasta `/(root)`. O endereço esperado será:

```text
https://victorsviartkliff.github.io/
```

## Busca e identidade

- Título, descrição, idioma e metadados Open Graph em português.
- Dados estruturados `Person` relacionando o nome artístico, o nome civil e os identificadores `xiaop` e `dorayakito`.
- `robots.txt` e `sitemap.xml` apontando para o endereço do GitHub Pages.
- Layout adaptável a dispositivos móveis e navegação com teclado.

Após a publicação, o endereço do sitemap para cadastrar no Google Search Console será `https://victorsviartkliff.github.io/sitemap.xml`. A indexação depende dos mecanismos de busca; o site fornece as informações para que possam rastreá-lo.

## Personalização

Os textos e metadados ficam em `index.html`; cores, tipografia e layout ficam em `styles.css`. Atualize o domínio nos metadados, no `robots.txt` e no `sitemap.xml` se passar a usar um domínio próprio.
